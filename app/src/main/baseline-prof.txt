# Baseline profile — the single biggest reason the UI felt slow.
#
# Without it, Android has to interpret / JIT-compile the whole Compose UI on every
# cold start, which is exactly what "scrolling takes forever" looks like on a real
# phone. With it, these methods are AOT-compiled at install time.
#
# H = hot, S = startup, P = post-startup. AGP rewrites these rules through the R8
# mapping automatically, so they keep working in the minified release build.
